# X-AVIS · 3D Operation System – Website

Statische Website mit Use-Case-Videos, Live-Kompositionen und dem interaktiven **Spatial AI Lab**.
Gehostet über Cloudflare Pages (kein Build-Schritt, Ausgabeverzeichnis `/`).

Dieser Ordner wird aus dem Projekt erzeugt, nicht von Hand bearbeitet:

```
cd C:\Dev\diss_lufahe_artefacts\diss_animation
npm run site:publish      # baut den Cloudflare-Export und kopiert ihn hierher
```
